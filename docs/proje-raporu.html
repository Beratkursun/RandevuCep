1. Uygulama ne yapıyor?

Kullanıcı; semt veya hizmete göre salon arar, hizmet ve berber seçer, uygun saati görür ve randevu alır. Berberler kendi PIN'leriyle ayrı bir panele girip randevularını yönetir, boş saatlerini kapatır ve kazancını görür. Yönetim paneli salon, hizmet, berber ve randevu kayıtlarını SQLite üzerinde tutar.

3. Mimari

  • Ön yüz: Astro statik üretim, Svelte 5 runes ekranları, React 19 yalnızca dekoratif bileşen, MDX bilgi sayfaları.
  • Masaüstü/mobil kabuk: Tauri v2; Rust tarafında randevu_olustur ve vt_* SQLite komutları.
  • Veri: Katalog src/lib/data.ts; yönetim ve müsaitlik verisi SQLite (rusqlite, 4 tablo); tarayıcıda aynı arayüzü localStorage yedeği karşılar.
  • Dokümantasyon grafiği: lat.md/ — 11 dosya, lat check temiz.

5. Çalıştırma

bun install
bun run dev          # http://127.0.0.1:1420
bun run tauri dev    # masaüstü kabuğu (SQLite burada etkin)
bun run test         # Vitest
bun run check        # svelte-check + lat check
bun run build        # statik üretim

6. Bilinen sınırlar

  • Müşteri tarafı berberi ad ile eşler; yönetim panelindeki salon/berber adı katalogla aynı olmalıdır.
  • “İlk müsait berber” seçildiğinde kapalı saat filtresi uygulanmaz.
  • Salon verisi temsilidir (12 kurgusal işletme); fotoğraflar yapay zekâ ile üretilmiş temsili görsellerdir.
  • Müşteri randevuları şu an localStorage'da; SQLite'a taşınması bir sonraki adımdır.
